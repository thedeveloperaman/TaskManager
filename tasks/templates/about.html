About Task Manager

Task Manager is a modern, user-friendly web application built with Django to help you organize, track, and manage your daily tasks efficiently.

  • Create, edit, and delete tasks with ease
  • Mark tasks as complete or incomplete
  • Categorize tasks: Work Personal Shopping Study Other
  • Register and securely log in to manage your personal task list
  • Modern, responsive, and intuitive interface

This project is open source and intended for learning, productivity, and as a foundation for more advanced task management solutions.
